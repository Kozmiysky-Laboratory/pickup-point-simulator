# Симулятор ПВЗ

Браузерная игра: вы сотрудник пункта выдачи. Смена длится 90 секунд. Клиенты называют артикул, вы ищете посылку на складе и выдаёте её. За верную выдачу — монеты и рейтинг, за ошибку и ожидание — штраф. После смены можно купить улучшения и начать следующий день.

На старте — главное меню: «Играть» и «Как играть». Управление мышью или пальцем: кнопки «Стойка» и «Склад», клик по посылке, кнопка «Выдать посылку».

Стойка, полки, посылки и покупатели нарисованы самой игрой. Отдельные картинки скачивать не нужно.

## Как открыть

Дважды щёлкните `index.html`. Игра откроется в браузере.

Node.js, npm и сервер не нужны. Движок Phaser лежит рядом, в `vendor/phaser.min.js`. Интернет для запуска не требуется.

## Файлы

- `index.html` — страница игры
- `game.js` — вся игра
- `vendor/phaser.min.js` — движок
- `favicon.svg` — значок вкладки
