# 📦 Симулятор ПВЗ (Pickup Point Simulator)

Браузерная аркадная игра на **Phaser 3**, в которой вы работаете сотрудником пункта выдачи заказов. Принимайте клиентов, находите посылки на складе по артикулам и выдавайте их, не теряя рейтинга. С каждым днём клиентов всё больше, а времени на всё — всё меньше!

---

## 🎮 Геймплей

### Основной цикл

1. **Смена длится 90 секунд.** К стойке выдачи с интервалом подходят клиенты и просят посылку с конкретным артикулом (например, `A-123`).
2. У вас есть **ограниченное время** на поиск посылки — на экране идёт таймер клиента.
3. Переключайтесь между **стойкой** и **складом**, кликайте на посылку с нужным артикулом и жмите «Выдать посылку».
4. Правильная выдача: **+10 монет, +1 рейтинг**. Ошибка: **−5 монет**. Если клиент не дождался — **−1 рейтинг**.
5. В конце смены открывается **магазин улучшений** — потратьте заработанное и переходите к следующему дню.

### Сложность

Каждый новый день становится тяжелее:
- клиенты приходят чаще,
- времени на поиск посылки меньше,
- на складе появляется больше «посторонних» посылок-приманок.

### Магазин улучшений

| Улучшение | Эффект | Макс. уровень |
|---|---|---|
| 👟 **Быстрые ботинки** | Клиент ждёт на 3 секунды дольше | 5 |
| 🔦 **Авто-подсветка** | Подсвечивает нужную полку на 3 секунды | 3 |
| 🏗️ **Расширение склада** | Добавляет ряды полок (D, E, F) | 3 |
| 🧑‍🤝‍🧑 **Помощник** | Автоматически выдаёт каждого 4-го клиента | 3 |

Цена каждого улучшения растёт с уровнем (множитель от 1.8 до 2.5).

## 🕹️ Управление

- **Мышь / тап** — единственный способ управления:
  - кнопки **«Стойка» / «Склад»** внизу экрана — переключение видов;
  - клик по посылке на складе — выбор;
  - кнопка **«Выдать посылку»** — выдача выбранной посылки клиенту.

## 🚀 Запуск

Требуется **Node.js** (v18 или новее).

```bash
# 1. Установить зависимости
npm install

# 2. Запустить dev-сервер
npm run dev
```

После запуска откройте в браузере адрес, который выведет Vite (по умолчанию `http://localhost:5173`).

### Продакшен-сборка

```bash
npm run build      # соберёт проект в папку dist/
npm run preview    # локальный просмотр собранной версии
```

## 📁 Структура проекта

```
├── index.html               # HTML-страница с контейнером игры
├── public/                  # Статика (иконки)
├── src/
│   ├── main.js              # Точка входа: конфиг Phaser и регистрация сцен
│   ├── config.js            # Баланс игры: константы, апгрейды, формула сложности
│   ├── scenes/
│   │   ├── BootScene.js     # Генерация процедурных текстур
│   │   ├── PreloadScene.js  # Предзагрузка ассетов
│   │   ├── GameScene.js     # Основная игровая сцена (смена, выдача, счёт)
│   │   └── ShopScene.js     # Итоги смены и магазин улучшений
│   ├── managers/
│   │   ├── ClientManager.js # Спавн клиентов, таймеры ожидания
│   │   └── WarehouseManager.js # Склад: полки, посылки, подсветка
│   └── ui/
│       └── FloatingText.js  # Всплывающие тексты («+10 монет» и т.п.)
```

### Ключевые параметры баланса (`src/config.js`)

- `SHIFT_DURATION_SEC: 90` — длительность смены;
- `CLIENT_TIMER_SEC: 20` — базовое время ожидания клиента;
- `SPAWN_MIN_MS / SPAWN_MAX_MS` — интервал прихода клиентов;
- `REWARD_COINS: 10` / `PENALTY_COINS: 5` — награда и штраф;
- `getDifficultyForDay()` — формула усложнения по дням.
