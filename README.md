# Симулятор ПВЗ

Браузерная игра от первого лица: вы сотрудник пункта выдачи. Смена длится 90 секунд. Клиент заходит в закрытый зал через дверь и подходит к стойке. Склад с пронумерованными ячейками находится за стеной, клиент его не видит. Возьмите нужную коробку и отнесите её клиенту. Верная выдача даёт 10 монет и +1 рейтинг, чужая посылка снимает 5 монет, если клиент не дождался — минус 1 рейтинг. Магазина улучшений нет.

В ячейке может лежать одна или две посылки. На стене над секциями подписаны диапазоны номеров.

## Как открыть

Дважды щёлкните `index.html`. Игра откроется в браузере.

Node.js, npm и сервер не нужны. Интернет для запуска не требуется: Three.js лежит рядом, в `vendor/three.min.js`.

## Управление

- WASD — ходьба
- мышь — осмотр (клик по экрану захватывает мышь, Esc — пауза)
- чувствительность мыши — ползунок в главном меню и в паузе, значение запоминается
- клик по коробке — взять в руки (заказ ещё не закрыт)
- клик по клиенту у стойки — отдать посылку
- правая кнопка или R — вернуть посылку на полку

## Файлы

- `index.html` — страница игры
- `game.js` — вся игра
- `vendor/three.min.js` — движок
- `favicon.svg` — значок вкладки
